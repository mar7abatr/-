# حزمة أدوات إنتاج الفيديو

هذه الحزمة تثبّت على جهازك الأدوات نفسها التي استخدمتها في إنتاج الفيديوهات والغلاف:

| الأداة | وظيفتها |
|---|---|
| FFmpeg | قص المقاطع وتحويلها وتصدير MP4 بترميز H.264 |
| pycairo | رسم الموشن غرافيك: الخرائط، وخطوط الربط، والإطارات، والأيقونات |
| Pillow + raqm | كتابة النص العربي متصلاً وصحيحاً بخط DIN Next |
| faster-whisper | تفريغ التعليق الصوتي مع توقيت كل كلمة للمزامنة |
| rembg | فصل الشخص عن الخلفية |
| LaMa | إزالة النصوص والشعارات من الصور |
| shapely | تجهيز حدود الخرائط |
| scipy | تصميم المؤثرات الصوتية |

## التثبيت

### ماك
1. ثبّت Homebrew من https://brew.sh إن لم يكن مثبتاً.
2. افتح Terminal داخل هذا المجلد واكتب:
```
bash install-mac.sh
```
ملاحظة: قد تظهر أثناء الفحص على ماك رسالة تبدأ بـ `objc[...]: Class AVF... is implemented in both`. هذه رسالة تحذير بلا أثر، لأن مكتبتين تحملان نسخة من الملف نفسه، ويمكنك تجاهلها.

### ويندوز
تعمل الأدوات على ويندوز من خلال WSL، أي نظام أوبونتو مدمج في ويندوز، لأن مكتبة تشكيل الحروف العربية لا تُثبَّت بسهولة على ويندوز مباشرة.
1. افتح PowerShell كمسؤول (Run as administrator) واكتب:
```
wsl --install -d Ubuntu
```
2. أعد تشغيل الجهاز، ثم افتح تطبيق Ubuntu وأنشئ اسم مستخدم وكلمة مرور.
3. انسخ هذا المجلد إلى مساحة أوبونتو، ثم شغّل المثبّت منها:
```
cp -r /mnt/c/Users/اسمك/Downloads/video-tools ~/
cd ~/video-tools
bash install-linux.sh
```
4. شغّل Claude Code من داخل أوبونتو أيضاً.

### لينكس (أوبونتو)
```
bash install-linux.sh
```

يستغرق التثبيت من 5 إلى 15 دقيقة حسب سرعة الإنترنت، وفي نهايته يفحص كل الأدوات ويعرض حالة كل واحدة منها.

### تنزيل نماذج الذكاء الاصطناعي (اختياري، حوالي 4 غيغابايت)
```
.venv/bin/python download_models.py
```
إن لم تنزّلها الآن، تُنزَّل تلقائياً عند أول استخدام.

## الاستخدام مع Claude Code
افتح Claude Code داخل هذا المجلد:
```
cd video-tools
claude
```
سيقرأ Claude Code ملف `CLAUDE.md` تلقائياً، ففيه طريقة العمل والمواصفات الافتراضية: الألوان 896829 و1D1D1D، وخط DIN Next، ومقاسات الريلز و16:9، وقواعد التحرير. بعدها ضع ملفاتك في المجلد واكتب طلبك كالمعتاد.

## محتويات المجلد
- `fonts/`: خطوط DIN Next العربية التي أرسلتها.
- `examples/`: أكواد الفيديوهات والغلاف التي أنتجناها، ليستند إليها Claude Code في المشاريع الجديدة.
- `check_tools.py`: يفحص أن كل الأدوات تعمل. شغّله بالأمر `.venv/bin/python check_tools.py`.
